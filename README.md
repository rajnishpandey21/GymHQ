# GymHQ Landing Website

Static landing page built with HTML, CSS and vanilla JavaScript only.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design + animations
- `script.js` — modal, WhatsApp contact flow, reveal animations

## Contact flow
The Contact buttons open a modal asking for:
- Name
- Gym Name
- City
- State

Submitting opens WhatsApp to **+91 80768 31603** with a pre-filled message.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will publish the site.
